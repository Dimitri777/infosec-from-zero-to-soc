# План действий: построение зрелых процессов ИБ с нуля

## Фаза 0 — Подготовка (1 неделя)
- [ ] Встречи с ключевыми стейкхолдерами (IT, юристы, руководство, владельцы процессов)
- [ ] Определение критичных бизнес-процессов и данных
- [ ] Сбор существующих документов и инструментов по безопасности

## Фаза 1 — Оценка (2–3 недели)
- [ ] Проведение высокоуровневого gap-анализа
- [ ] Документирование текущих практик управления доступом
- [ ] Проверка состояния резервного копирования и восстановления
- [ ] Проверка практик обработки персональных данных
- [ ] Формирование списка топ-5–7 рисков

## Фаза 2 — Фундамент (1–3 месяца)
- [ ] Внедрение базового процесса управления доступом
- [ ] Развёртывание / усиление защиты конечных точек
- [ ] Создание процедуры реагирования на инциденты (даже простой)
- [ ] Запуск сканирования уязвимостей критичных систем
- [ ] Подготовка и утверждение основной Политики ИБ
- [ ] Закрытие очевидных пробелов по 152-ФЗ

## Фаза 3 — Стабилизация (4–6 месяцев)
- [ ] Введение регулярного цикла управления уязвимостями
- [ ] Улучшение журналирования и базового мониторинга
- [ ] Проведение первых мероприятий по повышению осведомлённости
- [ ] Определение и начало отслеживания ключевых метрик
- [ ] Пересмотр и усиление контроля доступа третьих сторон

## Фаза 4 — Рост зрелости (7–12 месяцев)
- [ ] Формализация подхода к управлению рисками
- [ ] Усиление change management с точки зрения ИБ
- [ ] Расширение покрытия мониторингом
- [ ] Планирование штата и инструментов на следующий год
