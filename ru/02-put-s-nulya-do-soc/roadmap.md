# Дорожная карта: от нуля до SOC

## Визуальный таймлайн

```
Месяц 0          Месяц 3          Месяц 9          Месяц 18         Месяц 36
  |                |                |                |                |
  v                v                v                v                v
Пожарная      →  Функция       →  Отдел         →  Пред-SOC     →  SOC / MDR
команда           (процессы)       (команда)        (мониторинг)     (операции)
```

## Подробные этапы

### Этап 1: Пожарная команда (0–3 месяца)
- Ответственный: 1 человек или частичная занятость
- Фокус: только критичные риски
- Результаты:
  - Список главных рисков
  - Базовое управление доступом
  - Простая процедура реагирования на инциденты
  - Основная Политика ИБ
  - Быстрые победы по защите конечных точек и резервному копированию

### Этап 2: Функция (3–9 месяцев)
- Ответственный: выделенный специалист / руководитель направления ИБ
- Фокус: повторяемые процессы
- Результаты:
  - Цикл управления уязвимостями
  - Улучшенное журналирование
  - Базовое повышение осведомлённости
  - Первые метрики и отчётность руководству
  - Понятная матрица ответственности

### Этап 3: Отдел (9–18 месяцев)
- Ответственный: Руководитель ИБ + небольшая команда
- Фокус: покрытие и формализация
- Результаты:
  - Определённые роли
  - Процесс управления рисками
  - Улучшенный мониторинг / ранний SIEM
  - Требования безопасности к подрядчикам
  - Регулярные внутренние оценки

### Этап 4: Движение к SOC (18–36 месяцев)
- Варианты:
  A. Строить внутренний SOC (дорого, нужен масштаб)
  B. Сильная внутренняя команда + внешний MDR/SOC-сервис (чаще для компаний среднего размера)
- Фокус: возможности обнаружения и реагирования
- Результаты:
  - Use-case’ы и playbook’и
  - Непрерывный мониторинг критичных активов
  - Определённые SLA по обнаружению и реагированию
  - Интеграция с IT и кризисным управлением

## Точка принятия решения

Перед инвестициями в полноценный SOC ответьте на вопросы:
1. Генерируем ли мы достаточно ценных событий безопасности?
2. Есть ли (или можем ли нанять) люди, способные проводить расследования?
3. Готово ли руководство к стоимости 24/7-операций?
4. Не даст ли внешний MDR-сервис лучшую отдачу на текущем этапе?
