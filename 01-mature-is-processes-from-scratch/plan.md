# Action Plan: Building Mature IS Processes from Scratch

## Phase 0 — Preparation (Week 1)
- [ ] Meet key stakeholders (IT, Legal, Management, process owners)
- [ ] Identify critical business processes and data
- [ ] Collect existing security-related documents and tools

## Phase 1 — Assessment (Weeks 2–3)
- [ ] Conduct high-level gap analysis
- [ ] Document current access management practices
- [ ] Review backup and recovery status
- [ ] Check personal data processing practices
- [ ] List top 5–7 risks

## Phase 2 — Foundation (Months 1–3)
- [ ] Implement basic Access Management process
- [ ] Deploy / improve endpoint protection
- [ ] Create Incident Response procedure (even if simple)
- [ ] Launch vulnerability scanning for critical systems
- [ ] Draft and approve core IS Policy
- [ ] Address obvious personal data compliance gaps

## Phase 3 — Stabilization (Months 4–6)
- [ ] Introduce regular vulnerability management cycle
- [ ] Improve logging and basic monitoring
- [ ] Conduct first security awareness activities
- [ ] Define and start tracking key metrics
- [ ] Review and improve third-party access controls

## Phase 4 — Maturity Growth (Months 7–12)
- [ ] Formalize risk management approach
- [ ] Strengthen change management from security perspective
- [ ] Expand monitoring coverage
- [ ] Plan headcount and tool roadmap for the next year
