# Roadmap: From Zero to SOC

## Visual Timeline

```

  |                |                |                |                |

Firefighting  →  Function      →  Department    →  Pre-SOC      →  SOC / MDR
(gaps)           (processes)      (team)           (monitoring)     (operations)
```

## Detailed Stages

### Stage 1: Firefighting (0–3 months)
- Owner: 1 person or fractional resource
- Focus: Critical risks only
- Deliverables:
  - Top risks list
  - Basic Access Management
  - Simple Incident Response process
  - Core IS Policy
  - Quick wins on endpoint protection and backups

### Stage 2: Function (3–9 months)
- Owner: Dedicated IS specialist / lead
- Focus: Repeatable processes
- Deliverables:
  - Vulnerability Management cycle
  - Improved logging
  - Security awareness basics
  - First metrics and management reporting
  - Clear responsibility matrix

### Stage 3: Department (9–18 months)
- Owner: Head of Information Security + small team
- Focus: Coverage and formalization
- Deliverables:
  - Defined roles
  - Risk management process
  - Better monitoring / early SIEM
  - Vendor security requirements
  - Regular internal assessments

### Stage 4: Toward SOC (18–36 months)
- Options:
  A. Build internal SOC (expensive, requires scale)
  B. Strong internal team + external MDR/SOC service (more common for mid-size companies)
- Focus: Detection and response capability
- Deliverables:
  - Use cases and playbooks
  - Continuous monitoring coverage of critical assets
  - Defined SLAs for detection and response
  - Integration with IT and crisis management

## Decision Point

Before investing in a full SOC, answer:
1. Do we generate enough valuable security events?
2. Do we have (or can we hire) people who can investigate?
3. Is management ready for the cost of 24/7 operations?
4. Would an external MDR service give better value at this stage?
